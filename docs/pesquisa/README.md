# Pesquisa de conteúdo de saúde

Regra do projeto: **todo texto de saúde publicado no site precisa de uma entrada aqui**, com fonte primária, data de consulta e nível de evidência. Sem evidência, o site não afirma.

Níveis usados (simplificado):

| Nível | Significado |
|---|---|
| A | Revisão sistemática/meta-análise, ou diretriz oficial (OMS, Ministério da Saúde, sociedade científica) |
| B | Estudo observacional grande / coorte populacional |
| C | Consenso de especialistas, documento técnico, opinião |

Cada afirmação do site aponta para o arquivo e o item correspondente (ex.: `<tema>.md#1`).
